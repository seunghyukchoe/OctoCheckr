OctoCheckr User Guide

A native macOS utility for measuring photographed color charts and exporting correction values.

Version 0.2.0 · Local pre-release. Public downloads are not available yet. Editor integration, reference-data redistribution, signing and notarization remain under verification.

Workflow

  1. Prepare the photo

    Photograph your chart in the same lighting as the subject. Adjust white balance and exposure in your photo editor, then export an ICC-tagged TIFF, JPEG or PNG. Develop RAW files before opening them here.

  2. Select and align

    Choose the matching chart model and revision. Drag the numbered corners around the patch area. Rotate, flip or automatically align with the toolbar. Inspect patch comparisons and warnings before exporting.

  3. Choose a correction

    Use HSL for Adobe presets or the linear RGB matrix for ICC and cube LUT exports. The displayed ΔE76 is error on the chart used for fitting, not a guarantee of accuracy in another editor.

  4. Send or export

    For Lightroom Classic, use Set Up Plug-in, then register OctoCheckr.lrplugin in File → Plug-in Manager. Correction values refresh while Lightroom stays open. Apply them explicitly from Plug-in Extras; the plug-in creates a snapshot before applying HSL settings.

Camera ICC input conditions

ICC export checks the decoded source type, 16-bit sample depth and embedded ICC tag, including after rotation or flips. This does not establish the camera model, Linear Response curve or prior editing settings; confirm those conditions yourself. The selected base profile is read once with a 16 MiB limit and retained throughout export.

Lightroom catalog access

If Lightroom cannot obtain catalog write access within 15 seconds, OctoCheckr reports that the correction was not applied. Wait for the other operation to finish and run Apply Latest Correction again. Success is reported only after the SDK confirms execution.

Chart reference data

The local research build includes SpyderCheckr24 and ColorChecker Classic24 / Digital SG140 reference editions before and after November2014. Manufacturer data rights have not been cleared for public redistribution. Custom rectangular charts support 6–576 patches using Lab D50 or encoded sRGB JSON values. JSON references require at least two distinct neutral indices and must include the white and black indices in that list. Use the correct illuminant, observer, chart revision and patch order; individual-card measurements are preferable when available.

CGATS Lab files (.txt, .ti3, .cie) can be imported with D50/2° confirmation, chart dimensions, and A1 coordinate or row-major file order. Known conflicting measurement metadata is rejected. At least two neutral patches are required (Lab chroma ≤8, lightness span ≥10).

Settings and onboarding

Open Settings with ⌘,. Choose system/light/dark appearance, English/Korean language, file watching, automatic Lightroom value refresh and a default export destination. Settings can open the chart reference folder. The first-run guide is skippable and can be replayed from Help → Getting Started.

Image rotations and flips are in memory. The original photograph is not overwritten. File watching reloads external file changes and clears in-memory edits. A reimported chart ID replaces its validated stored reference; a malformed import preserves the previous version.

Watched changes immediately invalidate correction. Stable file observations trigger reload, and file identity detects atomic replacements even when size and time match. Export checks source freshness and correction version before writing.

Turning off file watching

If you turn off file watching after an update has already been detected, OctoCheckr finishes that pending reload before stopping further automatic detection. If the file is missing, reopen a photo to select a usable source.

Build and versions

Requires Xcode with a Swift6 toolchain; the deployment target is macOS13. The current local build is universal (arm64 and x86_64) and ad hoc signed. Local ZIP extraction, signature and SHA-256 checks pass. Developer ID signing and notarization are pending. Original code is MIT licensed; manufacturer data and sample photos are excluded from that license.
