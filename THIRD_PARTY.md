## Mechanical publication inventory

`reference-provenance.json` records the current SHA-256 of the four chart JSON files and the source file containing the Spyder table. Run `python3 Scripts/audit-publication.py` before preparing a public candidate. Exit2 currently reports five unresolved reference items. The tool also flags changed bytes, missing inventory/evidence files and unlisted chart resources, including non-JSON resources.

This checks recorded evidence and file identity, not whether a permission or license is legally sufficient. Status0 is not publication approval, editor compatibility, signing or notarization. Do not mark data documented merely because a download or mirror exists; keep the provenance and authoritative redistribution basis separate.
